# Pearls AQI Predictor

A serverless end-to-end machine learning system that forecasts the Air Quality Index (AQI) for **Islamabad, Pakistan** three days in advance — automated hourly data collection, daily model retraining, and a live web dashboard.

**🔗 Live Dashboard:** [https://aqi-predictor-3pqvughkm9hvev7nlavn6u.streamlit.app/](https://aqi-predictor-3pqvughkm9hvev7nlavn6u.streamlit.app/)

---

## Features

-  **3-day AQI forecast** using a Random Forest model (compared daily against Ridge Regression and TensorFlow)
-  **Hourly feature pipeline** — live pollutant + weather data via OpenWeather
-  **Daily training pipeline** — retrains, compares, and auto-promotes the best model
-  **Historical trend charts + AQI calendar heatmap**
-  **3-day weather forecast** (real meteorological data from Open-Meteo)
-  **Hazard alerts** when forecasted AQI crosses unhealthy thresholds
-  **SHAP explainability** — see why the model predicted what it predicted
-  **Fully automated via GitHub Actions** — no server maintained by hand

## Setup

### 1. Clone the repo
```bash
git clone https://github.com/rafayxali/aqi-predictor.git
cd aqi-predictor
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Set up environment variables
Create a `.env` file in the project root:
```env
OPENWEATHER_API_KEY=your_openweather_key
HOPSWORKS_API_KEY=your_hopsworks_key
HOPSWORKS_PROJECT=your_hopsworks_project_name
```

- Get an OpenWeather key at [openweathermap.org/api](https://openweathermap.org/api)
- Get Hopsworks credentials at [app.hopsworks.ai](https://app.hopsworks.ai)

## Running Locally

### Historical backfill (one-time)
```bash
python data_backfil.py     # builds data.csv (~2 years of daily data)
python push_hops.py        # pushes data.csv into the Hopsworks Feature Store
```

### Feature pipeline (normally runs hourly via GitHub Actions)
```bash
cd pipelines
python feature_pipeline.py
```

### Training pipeline (normally runs daily via GitHub Actions)
```bash
cd pipelines
python training_pipeline.py
```

### Backend (FastAPI)
```bash
cd app
uvicorn backend:app --reload --port 8000
```
Test it at `http://127.0.0.1:8000/predict`

### Frontend (Streamlit)
In a separate terminal, with the backend running:
```bash
cd app
streamlit run frontend.py
```

Set `BACKEND_URL` in your environment (or Streamlit secrets) if the backend isn't running on `localhost:8000`.

## Automation (GitHub Actions)

Two workflows run automatically once the repo is on GitHub:

| Workflow | Schedule | What it does |
|---|---|---|
| `feature_pipeline.yml` | Every hour | Fetches live AQI/weather data → Hopsworks |
| `training_pipeline.yml` | Daily | Retrains models, promotes the best to the Model Registry |

Required GitHub repo secrets: `OPENWEATHER_API_KEY`, `HOPSWORKS_API_KEY`, `HOPSWORKS_PROJECT`

Both can also be triggered manually from the **Actions** tab.
